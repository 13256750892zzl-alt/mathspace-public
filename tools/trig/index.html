[进阶] 负参数与诱导公式

A < 0：相对同一 B 的正振幅曲线关于平衡线 y = B 翻折；仅当 B = 0 时关于 x 轴翻折。最大值仍为 B + |A|。

ω < 0：可用诱导公式 sin(ωx+φ) = −sin(−ωx−φ) 化为 ω > 0 的形式。

平移量易错点（本课重点）

两条路线终点相同，但中间那一步的平移量差 ω 倍。口诀「左加右减」作用的对象是 x，不是 ωx。

快捷键与术语速查

【术语】
A  振幅：曲线偏离平衡位置的最大距离，|A| ≥ 0
ω  角频率：决定周期，ω 越大波形越密
φ  初相：x = 0 时的相位，决定左右平移
B  纵向平移：决定平衡位置，不改变周期

【五个参数的作用范围】
A 只影响纵向       → 值域、最大值、最小值变
ω 只影响横向       → 周期、单调区间、对称轴横坐标变
φ 只影响左右位置   → 对称轴、对称中心横坐标整体平移
B 只影响上下位置   → 值域、对称中心纵坐标变

【最容易错的一件事】
「左加右减」里的加减，加在 x 上，不是加在 ωx 上。
所以先伸缩后平移时，平移量是 |φ|/ω，而不是 |φ|。

M：变换链；C：双曲线；F：全屏；?：帮助
