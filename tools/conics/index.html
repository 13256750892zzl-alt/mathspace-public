快捷键与术语速查

两个参数决定一条圆锥曲线

e 离心率：决定形状。0 < e < 1 椭圆，e = 1 抛物线，e > 1 双曲线。d 焦准距：焦点到准线的距离。固定 e 改变 d，只改变大小。

从定义到方程

|MF₁| / d(M, l) = e
√(x² + y²) = e·|x + d|
ρ = ed / (1 − e·cos θ)（x + d > 0 的一侧）

统一极坐标式用于画椭圆、抛物线与双曲线右支；双曲线左支由关于中心的对称性补画。左支的到准线距离为 |x + d|，仍满足第二定义。

三个定义的等价性

椭圆     |MF₁| + |MF₂| = 2a，且 2a > |F₁F₂|
双曲线   ||MF₁| − |MF₂|| = 2a，且 0 < 2a < |F₁F₂|
抛物线   |MF₁| = d(M, l)

最容易错的一件事

椭圆的准线在焦点外侧；双曲线的准线位于两支之间。准线到中心的距离都是 a²/c。椭圆的 b/a = √(1 − e²)，不是 e。固定 d 时，改变 e 也会改变大小；比较形状应看 b/a。

圆与临界区

固定 d，e → 0 时曲线缩为点。固定半通径 p = ed、同时让 d → ∞，才得到圆。本工具的「圆」预设单独演示这个极限，半径 p = 4。e = 0.05 仍为椭圆。只有 e 精确为 1 才称抛物线，0.999 与 1.001 仍分别是椭圆、双曲线。
