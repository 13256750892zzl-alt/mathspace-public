04 / 从一次实验，走向一个方法

留三个问题，带走二分法。

01　从长度 1 到小于 0.1，要折半几次？到小于 0.01 呢？
n 次折半后，Lₙ = L₀ / 2ⁿ。要求 L₀ / 2ⁿ < ε，必须保留严格小于。
从长度 1 出发：1/2⁴ = 0.0625 < 0.1，需要 4 次；1/2⁷ = 0.0078125 < 0.01，需要 7 次。若 ε = 0.5，第一次长度恰为 0.5，还要再折半一次。
取三分之一点也可缩区间，但最坏会保留 2/3；取中点让两半同长，最坏也只保留 1/2。
02　f(a)·f(b) > 0，区间内就一定没有零点吗？
不能这样推断。函数在 [a,b] 连续且端点异号，可以保证内部至少有一个零点；反过来不成立。x² 在 [−1,1] 两端同为正，内部仍有零点 0；x²−2 在 [−2,2] 两端同为正，内部还有两个零点。
唯一性需要另行论证（如严格单调）。含多个零点的变号区间仍可二分，但通常只能锁定其中一个。
03　为什么区间内任意一点都合格？中点好在哪里？
若已保证零点 ξ 在 [a,b] 内，且 L = b−a < ε，则任意 x̃ ∈ [a,b] 满足 |x̃−ξ| ≤ L < ε；取中点能把误差上界进一步降到 L/2。
这是横坐标的误差保证，不是要求 |f(x̃)| < ε。表格中的近似小数要区分“接近 0”和“恰好为 0”；找到 f(m)=0 时可直接结束。
教师工具与课堂讨论

建议让学生先读 f(a)、f(m) 的符号再投票。这里的函数均连续；x²−2 在正区间严格递增，在负区间严格递减。图象观察不能替代存在性与唯一性的论证。
