# 数间 Mathspace

高中数学知识复习、专题练习、交互实验与学习资料的静态发布版。

- 首页：`index.html`；对照界面：`alche.html`。
- 知间：从知识复习进入章节选择，再进入知识问答卡。
- 23个交互工具位于 `tools/`，与已有的2个在线AI工具统一列在数学实验中。二次函数已迁入本站同域名入口，旧地址保留作备用。
- 2026-10-30新增幂函数家族、奇偶性、二分法、正弦/余弦函数的诞生、圆锥曲线的诞生、正态分布及最小二乘回归直线，均可从数学实验目录进入。
- 课序与错题系统暂未公开；本站没有账号、学生数据库、模型密钥或收费功能。
- 学习自评仅保存在当前浏览器，换电脑不会自动同步。

这是供学习与教师复核的工具集合。图像和数值观察不能代替数学证明。
前端依赖沿用各原项目版本与许可；Math.js、KaTeX、MathQuill、jQuery、Three.js及字体随站点提供。
